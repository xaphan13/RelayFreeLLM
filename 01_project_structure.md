# 01. Карта проекта (Project Structure)

## Назначение проекта
RelayFreeLLM — это open-source шлюз (gateway), который объединяет бесплатные уровни (free-tiers) различных провайдеров AI в единый API, совместимый с OpenAI. Главная цель проекта — обеспечить максимальную доступность и пропускную способность для AI-инференса без затрат, предоставляя автоматический failover, маршрутизацию по намерениям, управление контекстом и унификацию стилей ответов.

Проект спроектирован так, чтобы выступать прозрачной заменой для любого кода (например, использующего SDK от OpenAI) без необходимости изменения логики клиента — достаточно просто поменять `base_url`.

## Внешние зависимости и их роль

Система работает автономно и хранит состояние в in-memory структурах и локальных JSON-файлах, поэтому внешних баз данных или брокеров сообщений не требуется.

Ключевые зависимости (помимо стандартной библиотеки Python):
- **FastAPI / Uvicorn:** Фреймворк и ASGI-сервер для обработки HTTP и SSE (Server-Sent Events) запросов.
- **Pydantic:** Валидация входных данных, типизация конфигурации и парсинг структур данных (основа для реализации совместимости с OpenAI API).
- **Httpx:** Асинхронный HTTP-клиент для взаимодействия с API провайдеров.
- **Сторонние AI API (Google Gemini, Groq, Mistral, NVIDIA, DeepSeek, Cerebras, Cloudflare):** Выступают в роли исполнителей (workers) генерации текста и обработки изображений. Связь происходит исключительно по HTTP(S).
- **Ollama:** Опциональная зависимость для интеграции с локальными моделями.
